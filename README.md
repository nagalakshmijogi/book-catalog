# book-catalog
Book Catalog API - .NET Internship by Nagalakshmi Jogi

Details:

This project provides an API for book catalog with varies book related operations such as Create, Update, Get, Delete

Technical Details:
Project created using Visual Studio 2026,
.Net 10

Cotroller Details:

Name: Books

Endpoints:
Get:
used to get all books in the system

Get by Id:
Used to get specific book by its ID

Post:
Used to Create a book in the system

Update(Put):
Used to edit a existing book.

Delete:
Used to delete the book from database

further API details can be get from the Swagger when opened the API


Structure:
Controllers
	- BooksCntroller
Models
	-Book

Database:
Currently using a in-memory collection
